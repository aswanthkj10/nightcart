What each database does

  • Redis: live cart Hash, unique customer Set, activity List, checkout amount Sorted Set.
  • MongoDB: product documents, active-cart snapshots, order documents and activity log records.
  • MonetDB: relational sales rows and SQL revenue/units aggregates.
  • Neo4j: Product and Order nodes with RELATED_TO, BOUGHT_WITH and CONTAINS relationships.
